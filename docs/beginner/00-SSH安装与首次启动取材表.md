# 安装与首次启动：图文教程取材表

本文件规定后续真实 SSH 部署测试的拍摄节点，目前不是已拍成的教程。执行方案见 [阶段 3](../deployment-design-20261031/阶段3-SSH部署与教程截图验收.md)。

每个节点保留远端全屏无损 PNG；能最大化的窗口先最大化，不遮挡、不裁剪、不加隐私遮挡。相同节点根据实际需要留动作前、过程、结果三种状态，失败另存。首次与复装轮次分开，图片索引写明。用真实拍到的步骤编写图注，不用静态示意图补造过程。
